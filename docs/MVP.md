# ダラリカ / darareco 最小MVP仕様

## 1. 目的

このMVPは「正しい休養法」を教えるものではない。検証するのは、次の行動が低い摩擦で成立するかどうかである。

> 疲れたと気づく → 少数の休養候補から一つ選ぶ → 途中の思いつきを実行せず退避する → 休みに戻る → 軽く振り返る

中心仮説は以下。

> **疲れているとき、休養の選択肢を少数提示し、思いついた用事を実行せず退避できる場所を用意すると、「もう少し何かする」より「休む」を選びやすくなるか？**

医学的な回復量、疲労度、健康状態は評価しない。

## 2. 画面遷移

```text
[1. Start]
   ↓ 「休む」
[2. Recovery Check-in]
   ↓ 0〜1個を選ぶ / 選ばず進む
[3. Recovery Menu]
   ↓ 3候補から1つ選ぶ
[4. Recovery Session]
   ├─ Thought Parking → 1行保存 → 同じSessionへ戻る
   └─ 「休みを終える」
        ↓
[5. Reflection]
   ↓ 任意で1つ選ぶ / 記録せず終える
   完了
```

画面数は最大5。Thought Parkingは独立画面にせず、Session内の唯一の補助操作とする。

## 3. 各画面

### 3.1 Start

**目的:** 休むための入口を説明しすぎず、一手で開始できるようにする。

表示:
- `ダラリカ / darareco`
- 「だらだらすることを、ちゃんと選べるようにする。」
- 主ボタン「いま休む」

置かないもの:
- streak
- 今日の達成数
- 未達警告
- 生産性向上の訴求

### 3.2 Recovery Check-in

**目的:** 精密測定ではなく、休み方を選ぶ小さなきっかけにする。

0〜1個を任意選択:
- 頭が疲れている
- 身体が疲れている
- 刺激に疲れている
- 眠い
- なんとなく休みたい

必ず「選ばず進む」を許す。スコア化・診断・原因推定はしない。

### 3.3 Recovery Menu

**目的:** choice overloadを避け、選択を速くする。

候補プール:
- 何もしない 10分
- 横になる 20分
- 外を見る / 少し歩く 10分
- 温かい飲み物と休む 10分

一度に見せるのは3候補。Check-inを選んだ場合は候補の並びを軽く変えてよいが、「あなたにはこれが必要」など医学的・断定的な推薦表現はしない。

### 3.4 Recovery Session

**目的:** 休養中のアプリ操作を増やさない。

表示:
- 選んだ休み方
- 残り時間のシンプルな表示
- 「思いつきを置いておく」入力
- 「休みを終える」

タイマー終了時:
- 音や連続通知で急かさない
- 「時間です。急いで戻らなくて大丈夫。」程度の表示に変える
- 自動で作業再開へ送らない

#### Thought Parking

- 1行テキストのみ
- 保存後は入力を空にし、Sessionへそのまま戻す
- セッション中は一覧表示しない
- タスク化、期限、優先度、リマインダー、外部連携を置かない
- MVPではブラウザのlocalStorageへ保存する

狙いは「忘れたくないから今やる」を「忘れないから今やらなくてよい」に変えること。

### 3.5 Reflection

**目的:** Recovery Mapの種になり得る最小の主観データだけ残す。

任意選択:
- 少し休めた
- 変わらない
- 途中でやめた
- 記録せず終える

選択後は評価・点数・連続記録を表示しない。「今日はここまで。」で終える。

## 4. ローカルデータ

MVPではアカウントやDBを導入しない。

### `darareco.thoughts`

```json
[
  {
    "text": "あとで返信する",
    "createdAt": "ISO-8601"
  }
]
```

### `darareco.sessions`

```json
[
  {
    "checkIn": "head | body | stimulus | sleepy | rest | null",
    "recovery": "none | lie-down | outside | warm-drink",
    "plannedMinutes": 10,
    "startedAt": "ISO-8601",
    "endedAt": "ISO-8601",
    "reflection": "rested | same | stopped | null"
  }
]
```

内容は端末内だけに保存する。Thought Parkingの本文を分析・送信しない。

## 5. MVPに含めないもの

- Recovery Garden
- Recovery Map
- streak / バッジ / ポイント
- アカウント / 認証
- SNS
- クラウド同期
- 詳細日記
- 疲労スコア
- AI推薦
- 医療助言・診断
- タスク管理機能

## 6. 受け入れ条件

1. Startから3操作程度でRecovery Sessionを開始できる。
2. Check-inを選択しなくても進める。
3. Menuには一度に3候補だけ表示される。
4. 「何もしない」が正規の休養候補として存在する。
5. Session中にThought Parkingへ一行を保存し、そのまま休みに戻れる。
6. Parkingした内容をSession中にタスクとして処理する導線がない。
7. 「休みを終える」から任意のReflectionへ進める。
8. 休めなかった場合も失敗・未達・streak欠損として扱われない。
9. アカウントなし、ローカル保存のみで一周試せる。

## 7. 最初の観察ポイント

- 起動からSession開始まで迷わないか
- 3候補でも選択に負担があるか
- Check-inは助けになるか、むしろ邪魔か
- Thought Parkingを使ったあと本当に休みに戻れるか
- Session画面をもっと削れるか

Garden / Mapの追加判断は、このフローを実際に使った後に行う。
