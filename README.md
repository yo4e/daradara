# ダラリカ / darareco

**だらだらすることを、ちゃんと選べるようにする。**

ダラリカは、疲れているときに「もう少し何かする」より、**いま休む**を選びやすくするための行動設計ツールです。

生産性を上げるための休憩管理や、疲労を精密に測る健康アプリではありません。休む理由を証明しなくても、少ない操作で休養を始め、途中で浮かんだ用事を未来へ預け、いまの休みに戻れることを目指します。

> **ダラリカ / darareco**  
> だらだらすることを、ちゃんと選べるようにする。

## 現在のMVP

最初に検証する問いは一つです。

> **疲れているとき、休養の選択肢を少数提示し、思いついた用事を実行せず退避できる場所を用意すると、「もう少し何かする」より「休む」を選びやすくなるか？**

MVPは次の流れだけに絞ります。

1. **Recovery Check-in** — 「頭が疲れている」「身体が疲れている」などを任意で一つ選ぶ。選ばず進んでもよい。
2. **Recovery Menu** — 選択肢を3つだけ提示し、休み方を一つ選ぶ。
3. **Recovery Session** — シンプルなタイマーで休む。アプリ操作を増やさない。
4. **Thought Parking** — 思いついた用事やアイデアを一行だけ退避し、その場では実行しない。
5. **終了時の軽い振り返り** — 「少し休めた」「変わらない」「途中でやめた」から任意で一つ残す。

画面遷移と仕様の詳細は [`docs/MVP.md`](docs/MVP.md) にあります。

## プロトタイプ

`prototype/` に、ビルド不要の最小プロトタイプがあります。

```bash
cd prototype
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと、次の一連の流れを試せます。

> 疲れた → 休養を選ぶ → Thought Parking → 休む → 軽く振り返る

データはブラウザの `localStorage` にだけ保存します。アカウント、サーバー、外部送信はありません。

## プロダクト原則

1. 休養を生産性の従属物にしない。
2. 休むための操作を増やしすぎない。
3. 休めなかった日を失敗扱いしない。
4. 数字で身体状態を分かったふりをしない。
5. 医療診断・治療の代替を目指さない。
6. 「何もしない」を正当な選択肢として扱う。
7. 思いついた用事を、その場で実行する導線に変えない。

## 今回は入れないもの

- Recovery Garden
- Recovery Map
- streak / 連続記録
- アカウント
- SNS機能
- 精密な統計
- AIによる健康判定
- 医療・診断機能
- 高機能なタスク管理

Garden / Map は、まず「休む選択」が実際に起きるかを試してから判断します。

## 名前について

対外名称の本命は **ダラリカ / darareco** です。日本語では「ダラリカ」を主表記、`darareco` を英字表記として併記します。

`daradara` はこの構想の原型・コードネームとして残します。

ネーミング調査は一次スクリーニングであり、正式公開前には商標、ドメイン、主要SNSハンドル等を再確認します。
